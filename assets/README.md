# Final Gate brand kit

| File | Use |
|---|---|
| `svg/logo-mark.svg` | Gate emblem (standalone mark, favicon source) |
| `svg/logo-horizontal.svg`, `svg/logo-stacked.svg` | Full logo with "Final Gate" wordmark and tagline. The wordmark uses the Grenze Gotisch font from Google Fonts and falls back to Georgia if the font can't load. |
| `svg/app-icon.svg`, `svg/app-icon-maskable.svg` | Rounded app icon and full-bleed Android maskable icon |
| `svg/classes/*.svg` | Hero class badges: swordsman, shaman, archer, gunner, brawler |
| `svg/ui/*.svg` | UI icons (24×24, stroke uses `currentColor`) |
| `png/favicon-*.png` | Favicons 16–512 px |
| `png/app-icon-*.png` | Home-screen icons: 180 (iOS), 192 and 512 (Android), maskable 512 |
| `png/class-*.png` | Class badges, 200×220 |

Colors: gold `#fff0b8 → #f6bd4f → #a8621a`, night purple `#3b2675 → #140e29`, background `#14111f`.
